# HTML-testwebsite voor Authentik

Deze map bevat de twee HTML-pagina's en de Nginx-configuratie van de oorspronkelijke Authentik-test. De Compose-configuratie gebruikt het netwerk van de [bijbehorende Authentik-server](../authentik-server/README.md).

Zie het [testverslag](../authentik_test_documentatie.md) voor de opstelling en screenshots.
